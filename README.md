Repositorio con proyectos y ejercicios de la asignatura **Web 1: Desarrollo Web**.

## 📂 Contenido del Repositorio

Este repositorio contiene 6 proyectos independientes que demuestran conceptos clave de desarrollo web:

### 1. **HojaDeVida/** - CV Interactivo
Página personal que presenta mi perfil profesional, experiencia, habilidades técnicas y objetivos como desarrollador.
- HTML semántico con estructura clara
- CSS con diseño profesional
- Secciones: Perfil, Experiencia, Habilidades, Educación, Proyectos

### 2. **Tabla/** - Introducción a Tablas HTML
Proyecto educativo sobre estructuración de tablas HTML con datos de tecnologías web.
- Tabla con encabezados y celdas de datos
- Video embedded de YouTube sobre desarrollo web
- Estilos CSS profesionales con bordes y colores

### 3. **inputs/** - Panel de Gestión de Inventario
Aplicación interactiva con formulario y gestión dinámica de productos.
- Formulario para registrar productos (nombre, precio, imagen)
- JavaScript para crear tarjetas de productos dinámicamente
- Tema oscuro (dark mode) moderno
- Bootstrap para responsive design

### 4. **posicionamiento/** - Ejemplos de CSS Positioning
Demostración práctica de todos los tipos de posicionamiento CSS.
- Position: Static, Relative, Absolute, Fixed, Sticky
- Ejemplos visuales interactivos
- Explicaciones claras de cada tipo

### 5. **Fetch_API/** - Consumo de API Externa
Aplicación que consume la PokeAPI para mostrar una galería de Pokémon.
- Fetch API para consultas HTTP asincrónicas
- Manipulación del DOM con JavaScript
- Tarjetas con información de altura y peso
- Bootstrap para estilos responsive

### 6. **portafolio/** - Portafolio Profesional Moderno
Portafolio personal con diseño minimalista y moderno.
- Navbar sticky
- Sección Hero con stats
- Galería de proyectos con animaciones
- Sección de contacto
- Dark theme con accent en amarillo
- Totalmente responsive

## 🎯 Conceptos Aprendidos

- ✅ HTML Semántico y Estructura
- ✅ CSS: Flexbox, Grid, Posicionamiento
- ✅ JavaScript: DOM, Eventos, Fetch API
- ✅ Responsive Design
- ✅ Consumo de APIs Externas
- ✅ Formularios y Validación
- ✅ Dark Mode y UI/UX
